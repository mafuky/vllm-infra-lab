# 自建 vs 百炼 API 的单请求成本（2026-10-15）

- 自建：优云智算 RTX 4090 48G 按量 3.17 元/小时，显存限制 0.45，Qwen3-8B BF16，按拐点并发 16 的实测吞吐计算。
- API：百炼 qwen3.8-flash，北京地域输入 0.8 元、输出 2.7 元 / 百万 token（2026-10-13 价格页）。
- 每个请求输入 1024、输出 256 token，与压测同形状。
- **两边不是同一个模型**：百炼已不提供 qwen3-8b，flash 的效果通常强于 8B。比的是「自建 8B」和「云端最便宜档」的单价，不是同模型对比。
- 只算 GPU 租金，不含运维人力、存储、网络和闲置时段。

数据来源：results/bench/baseline/c16.json（并发 16，请求吞吐 2.31 个/秒）

| GPU 利用率 | 自建 元/请求 | API 元/请求 | 自建 元/百万 token | 单卡日上限 请求/天 |
| --- | --- | --- | --- | --- |
| 100% | 0.00038 | 0.00151 | 0.30 | 199,657 |
| 30% | 0.00127 | 0.00151 | 0.99 | 59,897 |

盈亏平衡：每天超过 50,371 个请求，租一张卡全天运行比调用 API 便宜。
